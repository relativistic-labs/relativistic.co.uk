# Relativistic

The launch site for Relativistic: AI-infused product development and consultancy.

A dependency-free static site with a responsive Canvas particle animation. Particles transition between a sphere, orbital rings, a wave and a scattered field. Pointer interaction, a pause control and reduced-motion preferences are supported.

## Local preview

Run `python3 -m http.server 8080` and open http://localhost:8080.

## Publishing

Pushes to `main` deploy through GitHub Actions to GitHub Pages. In repository Settings → Pages, use GitHub Actions as the source.

The intended custom domain is `relativistic.co.uk`. Configure its DNS and verify domain ownership before adding the custom domain in Pages settings. GitHub's current custom-domain instructions: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site

No contact address is published until a working mailbox is confirmed.
